## Структура проекта
```
burmaldaMelon/
├── app/                  # Основной модуль: UI, загрузчик .obj, рендеринг
│   ├── src/              # Исходный код (main, test)
│   └── pom.xml           # POM-файл модуля app
├── MathLib/              # Библиотека 3D-математики (векторы, матрицы)
│   ├── pom.xml           # POM-файл модуля MathLib
│   └── README.md         # Документация модуля MathLib
├── .gitignore            # Исключения для Git
├── pom.xml               # Корневой (родительский) POM-агрегатор
└── README.md             # Главный файл документации
```


## MathLib

Вспомогательная библиотека с математическим аппаратом для 3D-графики:

    Векторы (Vector2, Vector3, Vector4);

    Матрицы (Matrix3x3, Matrix4x4);

    Кватернионы и операции поворота;

    Утилиты для трансформаций (перенос, масштаб, вращение).

Собирается в отдельный .jar и подключается как зависимость к app.

## Сборка проекта

### Сборка выполняется из корневой директории:
```
mvn clean install -DskipTests
```

### Собрать все модули с тестами:
```
mvn clean install
```
После сборки артефакты появятся в папках target/ соответствующих модулей.


## Разработка
### Импорт в IntelliJ IDEA
    File → Open → корневая папка burmaldaMelon.
    Дождитесь синхронизации Maven.

### Работа с Git
```
git clone <URL_репозитория>
cd burmaldaMelon
git checkout -b feature/my-feature
```

Тестирование
```
# Все тесты
mvn test
```
# Тесты конкретного модуля
```
mvn test -pl MathLib
mvn test -pl app
```
